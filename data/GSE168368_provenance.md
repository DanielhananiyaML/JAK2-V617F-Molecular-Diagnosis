# GSE168368 Data Provenance

Public NCBI GEO series: **GSE168368**

BioProject: **PRJNA707039**

SRA: **SRP310755**

Organism: Homo sapiens

Experiment: high-throughput transcriptome profiling of megakaryocyte-erythroid progenitors in MPN subtypes and healthy controls.

The GEO series contains 29 samples and provides a processed gene-count matrix named `GSE168368_gene_count_matrix.csv.gz`.

The processed matrix is public and should be retrieved directly from NCBI. Raw sequencing data are available through SRA. This repository does not redistribute controlled-access human sequencing data.

Important analytical distinction: GSE168368 is an expression dataset. It provides real MPN biological context but is not itself a JAK2 V617F variant-calling dataset. Canonical JAK2 V617F identity is established independently from reference and variant databases.
